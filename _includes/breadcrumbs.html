{%- comment -%} Override of Minimal Mistakes' _includes/breadcrumbs.html. Builds the crumb list from two complementary sources: (A) The current page's `parent` front matter, followed recursively (up to 5 levels). Use this when the URL doesn't reflect the logical hierarchy — e.g. `/proteomics/` with `parent: /methods/` renders "Home / Methods / Proteomics". (B) The URL path segments of `page.url`. For each intermediate prefix we look up a page by permalink and also follow that page's OWN `parent` chain — so a child like `/protocols05/DIA/` picks up LC-MS's declared parent (Methods) and renders "Home / Methods / LC-MS / DIA" even though only the index page carries the `parent:` key. Duplicates across (A) and (B) are de-duplicated via a pipe-delimited accumulator. {%- endcomment -%} {%- assign crumb_urls = "|" -%} {%- comment -%} (A) Current page's parent chain, root-first. {%- endcomment -%} {%- assign chain_a = "" -%} {%- assign cursor = page.parent -%} {%- for _ in (1..5) -%} {%- if cursor == blank -%}{%- break -%}{%- endif -%} {%- assign chain_a = cursor | append: "|" | append: chain_a -%} {%- assign parent_page = site.pages | where: "permalink", cursor | first -%} {%- assign cursor = parent_page.parent | default: "" -%} {%- endfor -%} {%- assign crumb_urls = crumb_urls | append: chain_a -%} {%- comment -%} (B) URL walk;
