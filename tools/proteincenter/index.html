    Proxeon’s ProteinCenter

    On this page

    • UWPR ProteinCenter login
    • ProteinCenter manual

    The UWPR is pleased to have a partnership with Proxeon which gives our Resource researchers access to Proxeon’s ProteinCenter software. Please visit the ProteinCenter link above to learn more about all the features available in ProteinCenter.

    ProteinCenter nicely complements the set of software tools currently used and being developed at the UWPR. The software facilitates data interpretation, multiple run comparisons, and allows a biologist to quickly drill down and find the answers to the questions that they want to discover from their proteomics datasets. This is all accomplished via a web based user interface that you can access from any desktop with a web browser. The interface is layed out intuitively, has rich functionality, and, most importantly, is easy to use.

    UWPR collaborators that are interested in using ProteinCenter to interpret their data should contact Jimmy Eng <engj@ u.washington.edu> for an account.

    We would like to thank Christian Ingrell and the Proxeon team for choosing the UWPR to be a ProteinCenter reference site.

    Current version os of 09/18/2014: Software Version 3.13.2003, Build RELEASE_3_13_2003.1

    03/24/2010 - Version 3.2 updates includes:

    • Heatmaps to display quantitative data on a protein or biological annotation level
    • Expression profiling on annotation level, e.g. KEGG pathways – match your quantitative data on pathways
    • Direct support of the iProphet xml-format
    • Improvement in support of MaxQuant
    • Improvement in support of Spectrum Mill - now most used modifications are recognized
    • Improvement in support of CSV-format - now encode modification in peptide sequence
