    View data link issue

    On this page

    {width=”600” height=”180”}

    The username to access the “View Data” link is the same username that you use to log into the UWPR project website. If you’re not able to access the “View Data” link, try changing your password on the UWPR project page. By changing/resetting your password, this sets the password for both the project page server as well as the “View Data” link server. Feel free to re-use the same password you’re using now as the goal isn’t to change your password but re-set it in the secondary password file.

    The password update needs to happen via the page below and not via the “Forgot password?” option on the main UWPR site.

    If you’re still not able to access your data links after doing this, send us an email and we’ll intervene.
