*A compact nano-flow UHPLC system*

The Vanquish Neo is a UHPLC system for nano-, capillary-, and micro-flow LC-MS with a pressure rating of 1500 bar.

![]({{ site.baseurl }}/assets/images/instruments/VanquishNeo_01.png)

## System specifications {#specifications}

| Specification | Value |
|:--|:--|
| System pressure | up to 1500 bar (21,750 psi) |
| Flow range | 1 nL/min – 100 µL/min, in 1 nL increments |
| Recommended flow range | 100 nL/min – 100 µL/min |
| Injection volume range | 0.01 – 25 µL |
| Injection precision, 0.05–0.20 µL | ≤ 5.0% RSD |
| Injection precision, 0.20–0.50 µL | ≤ 1.5% RSD |
| Injection precision, 0.50–2.00 µL | ≤ 0.5% RSD |
| Injection precision, above 2 µL | ≤ 0.25% RSD |
