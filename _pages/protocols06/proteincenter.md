The UWPR is pleased to have a partnership with Proxeon which gives our Resource researchers access to Proxeon's [ProteinCenter](http://www.proxeon.com/productrange/data_interpretation/introduction/) software. Please visit the ProteinCenter link above to learn more about all the features available in ProteinCenter.

ProteinCenter nicely complements the set of software tools currently used and being developed at the UWPR. The software facilitates data interpretation, multiple run comparisons, and allows a biologist to quickly drill down and find the answers to the questions that they want to discover from their proteomics datasets. This is all accomplished via a web based user interface that you can access from any desktop with a web browser. The interface is layed out intuitively, has rich functionality, and, most importantly, is easy to use.

UWPR collaborators that are interested in using ProteinCenter to interpret their data should contact Jimmy Eng \<engj@ u.washington.edu\> for an account.

We would like to thank Christian Ingrell and the Proxeon team for choosing the UWPR to be a ProteinCenter reference site.
