## Authentication issue

*Fixing password authentication to search results*

If you are not able to access processed data links using the same username and password to log into the UWPR project system, please try re-setting your password. This will re-write a password file which may be the issue. You don't have to select a new password; just entering your password again will allow our Apache web server password file to be properly updated.

If you don't know your UWPR project application password, click on the "Forgot your password?" link on the top left corner of this page and recover your password.

1.  Log into the UWPR project application.  
    ![]({{ site.baseurl }}/misc/authentication/snapshot1.png){width="500"}
2.  Click on the "Account" tab.  
    ![]({{ site.baseurl }}/misc/authentication/snapshot2.png){width="500"}
3.  Click the "Password" link.  
    ![]({{ site.baseurl }}/misc/authentication/snapshot3.png){width="500"}
4.  Set your password and hit "Save". As I mentioned above, you don't have to choose a new password. You just have to set any password here (go ahead and re-type your current password) so that it gets propogated to our other password file that controls access to your search results.  
    ![]({{ site.baseurl }}/misc/authentication/snapshot4.png){width="500"}
5.  Now try to access your data again using the username and password you just set. If you have any questions or problems, contact me at engj@uw.edu.
